# المساعد الذكي

تطبيق Android عربي مستقل لإدارة العملاء والأرصدة والاستحقاقات والمخزون والتقارير والتذكيرات، مع واجهة مساعد ذكي.

## التصميم
- RTL عربي بالكامل
- Flat Design
- Dashboard/Grid + Accordion
- ألوان هوية: أزرق ذكي + تركوازي
- واجهة هاتفية واضحة ومتجاوبة

## البناء
يتم بناء APK تلقائياً عبر GitHub Actions عند الدفع إلى main أو يدوياً من Actions > Android Build.
